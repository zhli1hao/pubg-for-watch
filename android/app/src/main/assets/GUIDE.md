# PUBG Watch 3D · 操作指引
## 启动
打开 App → 显示 STARTING... 启动界面（约1.2秒）→ 自动进入登录/大厅。
## 登录（四种）
- 账号登录/注册：昵称 + 两层密码。
- 设备登录/注册：自动读取设备名/ID，填序列号 + 自定义密码。
- 游客登录：昵称 + 一层密码（30天未登录自动注销）。
- 开发者登录：账号 001 / 密码 admin123，验证后二次设置昵称+密码。
## 大厅
- 左下选地图（平原/Erangel-lite/沙漠），点击切换。
- 下方选模式（Solo/1v1/2v2/2v1/3v3）。
- 开始游戏：单机直接进入 3D 大逃杀。
- 创建/加入房间：局域网联机，名称+密码，人数不足 bot 补位。
## 联机/聊天
- 建房后把主机 IP/房间名/密码告诉好友加入。
- 房间内可文字聊天；语音按钮开启 LAN 语音（同网段）。
- 实时同步位置/射击/淘汰；断线自动重连（指数退避）。
## 好友
- 大厅→好友→搜索昵称/ID（ID 按注册顺序编号，昵称唯一）→ 添加。
- 启用 Firebase 后跨设备云端同步。
## 包体
- 单包名多 ABI（arm32/arm64/x86）默认；arm32/arm64 workflow 可分别产出单 ABI 最小包。
- 版本：0.0.1-Beta。
